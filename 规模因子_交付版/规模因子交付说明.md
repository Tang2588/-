## 2. 数据来源

直接复用 EP 已经清洗好的行情数据：

    D:\因子计算\市盈率\EP因子_交付版\中间结果\_mkt_clean.parquet

规模因子不需要利润表或资产负债表，不使用 N_INCOME_ATTR_P、T_EQUITY_ATTR_P 或 TTM。

使用字段：

    date
    code6
    me_total
    suspended
    is_cixin

## 3. 原始规模因子

规模因子采用总市值的自然对数：

    size_raw = ln(me_total)

计算前要求 me_total > 0。总市值为空或小于等于 0 时，规模因子设为缺失。**T 日停牌设为缺失**；次新股不筛除，仅在掩码中记录 `is_cixin` 供追溯（与 EP 口径一致）。历史 ST/PT 标记不可用，因此没有推断 ST/PT。

## 4. 时间口径

T 日的规模因子使用 T 日行情中的总市值：

    Size_T = ln(T日总市值)

T 日因子用于 T+1 日交易。T 日停牌时，T 日规模因子为空；T+1 日复牌后重新计算的因子用于 T+2 日交易。

## 5. MAD 和 Z 标准化

每日横截面处理：

    median = 当日 size_raw 中位数
    MAD = median(abs(size_raw - median))
    scale = 1.4826 * MAD
    下限 = median - 3 * scale
    上限 = median + 3 * scale

先将超出上下限的 size_raw 截断，再计算：

    size_signal = (MAD处理后的size_raw - 当日均值) / 当日标准差

signal 越高代表市值越大，越低代表市值越小。若构造小市值方向的组合，可以在回测时使用 -signal。

## 6. 与 Fama-French SMB 的区别

本文件输出的是逐股票规模暴露：

    index = ['date', 'stock_code']
    columns = ['signal']

它不是 Fama-French 的 SMB 组合收益。SMB 需要按市值分组，计算小市值组合和大市值组合的未来收益差，单独输出组合收益时间序列。

## 7. 运行顺序

    python size_step1_复用EP行情.py
    python size_step2_计算对数市值.py
    python size_step3_MAD去极值_Z标准化.py
    python verify_size.py

## 8. 验证内容

verify_size.py 检查：

1. 输出索引和列格式；
2. 日期和股票代码是否重复；
3. 是否存在无穷值；
4. 原始规模是否等于 ln(me_total)；
5. 非正市值是否为空；
6. MAD 去极值数量是否与统计表一致；
7. 每日 Z 值均值是否约等于 0；
8. 每日 Z 值标准差是否约等于 1。
