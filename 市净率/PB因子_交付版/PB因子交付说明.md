# PB 因子计算交付说明

## 1. 交付内容

交付目录：D:\因子计算\市净率\PB因子_交付版

正式因子文件为 因子结果\pb.parquet，格式为：

    index = ['date', 'stock_code']
    columns = ['signal']

signal 是经过 MAD 去极值和横截面 Z 标准化后的 PB。

## 2. 输入和字段

已清洗行情表：

    D:\因子计算\市盈率\EP因子_交付版\中间结果\_mkt_clean.parquet

资产负债表数据：

    D:\实习生学习项目\基础数据\vw_fdmt_bs_new.parquet

使用字段：

    TICKER_SYMBOL
    ACT_PUBTIME
    UPDATE_TIME
    END_DATE
    FISCAL_PERIOD
    MERGED_FLAG
    T_EQUITY_ATTR_P

T_EQUITY_ATTR_P 是归属于母公司股东权益，使用合并报表 MERGED_FLAG=1，作为 PB 的账面权益分母。

## 3. 计算口径

    PB_T = T日总市值 / T日最新可获得的归母股东权益

T 日因子使用 T+1 日交易。财报版本可用时间定义为：

    VERSION_TIME = max(ACT_PUBTIME, UPDATE_TIME)

对每个 T 日选择 VERSION_TIME <= T 日结束时间的最新权益快照。

归母权益为负时，保留负 PB：

    book_equity_parent < 0
    PB = market_cap / book_equity_parent < 0
    negative_book_equity = 1

负 PB 表示资不抵债或负净资产风险，不把它当作普通的低估值 PB 解读，但保留其排序信息。归母权益等于 0 时 PB 无定义，设为缺失。总市值必须大于 0。

## 4. 清洗和计算流程

### Step 1：读取行情

复制并检查已经清洗好的行情表，验证 date + code6 唯一，保留总市值、停牌和次新股掩码。

### Step 2：资产负债表清洗

1. 股票代码统一为 6 位。
2. 保留合并报表 MERGED_FLAG=1。
3. 保留累计报告期，要求 END_DATE 月份等于 FISCAL_PERIOD。
4. 完全重复的记录删除。
5. 同一报告期但权益值不同的修订版本保留。
6. 使用 ACT_PUBTIME、UPDATE_TIME 构造版本可用时间。

权益字段异常处理：

1. 原始资产负债表中有 2 条 T_EQUITY_ATTR_P 缺失记录。原始数据保留，但不进入权益版本清洗表；不能用 0、前一期或后一期权益填补。
2. 有 10,793 条记录无法解析为六位股票代码，主要是 Axxxxx 形式，例如 A19110、A20471。这些记录不能可靠地与行情表匹配，原始数据保留，但不进入权益清洗和因子计算。
3. 不直接截取数字或补零匹配异常代码，避免把财务主体错误匹配到其他股票；以后有证券代码映射表时再复核。
4. 完全重复记录额外删除 2 条；同一报告期不同修订版本保留。

权益清洗统计：

    原始记录：453,920
    MERGED_FLAG=1：272,641
    有效六位代码和权益字段后：266,910
    删除完全重复记录：2
    最终权益版本：266,908
    负归母权益：1,897
    权益等于零：0
    同一有效版本时间权益冲突：0

这里的排除只表示不进入因子计算，原始异常记录不物理删除。

### Step 3：点时权益快照

资产负债表是报告期末时点数据，不计算 TTM。按版本时间更新每个报告期权益，并在每个版本事件中选择报告期最新的权益值。

### Step 4：原始 PB

停牌、次新股、总市值无效、归母权益缺失或归母权益为 0 的记录不计算 PB。负归母权益记录保留为负 PB，并在 pb_mask.parquet 中记录 negative_book_equity。

### Step 5：MAD 和 Z 标准化

每日横截面计算：

    MAD = median(abs(PB - median(PB)))
    下限 = median - 3 * 1.4826 * MAD
    上限 = median + 3 * 1.4826 * MAD
    Z(PB) = (MAD处理后的PB - 当日均值) / 当日标准差

负 PB 参与横截面处理。当前数据中 MAD 下限仍为负，因此负 PB 没有被截成正值。

## 5. 实际数据案例

### 财报修订

股票 000002 的 2022-12-31 归母权益有多个版本。修订前的 T 日使用前一个版本，修订后才使用后一个版本，不回填历史。

### 完全重复记录

002499 的 2018-12-31 和 603895 的 2023-12-31 各自存在完全重复入库记录。它们是同一股票内部的重复，不是两只股票互相重复。相同股票、报告期、公告时间、更新时间和权益值的重复行只保留一条。

### 负净资产

000023 的部分报告期归母权益为负，对应 PB 保留为负值，并在掩码中标记负净资产。

### MAD 处理

极端 PB 在每日横截面 MAD 范围之外时，截断到当日上下限后再标准化。
