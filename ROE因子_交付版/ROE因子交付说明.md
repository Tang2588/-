# ROE 因子计算交付说明

## 1. 交付目录

交付目录：D:\因子计算\ROE因子_交付版

正式输出为：因子结果\roe.parquet。

    index = ['date', 'stock_code']
    columns = ['signal']

signal 是经过 MAD 去极值和每日横截面 Z 标准化后的 ROE。

## 2. 重要变更：直接复用 EP 数据

ROE 不再重复从原始利润表清洗 N_INCOME_ATTR_P。EP 已经完成了合并报表筛选、版本处理和 TTM 计算，ROE 直接复用：

    D:\因子计算\市盈率\EP因子_交付版\中间结果\reports.parquet
    D:\因子计算\市盈率\EP因子_交付版\中间结果\reports_ttm.parquet

ROE Step 2 只检查 EP 清洗结果的字段和唯一键，并将 EP 的利润版本和 TTM 文件复制到 ROE 中间结果目录，不重新读取和清洗原始利润表。

因此，ROE 与 EP 使用完全相同的归母净利润和 TTM 口径。EP reports.parquet 与 ROE 复用前后的利润版本均为 266,865 行，字段值完全一致。

不能直接使用 EP 最终的 ep.parquet，因为它是标准化后的 EP 信号。ROE 使用的是 EP 的中间结果 reports_ttm.parquet。

## 3. ROE 使用的数据

利润部分复用 EP：

    N_INCOME_ATTR_P       # 归属于母公司股东的净利润
    TTM_ni                # TTM归母净利润

权益部分复用 PB 已清洗的：

    T_EQUITY_ATTR_P       # 归属于母公司股东权益

两者均为合并报表中的归母口径，归属范围一致。

权益清洗异常记录：

1. 原始资产负债表中有 2 条 T_EQUITY_ATTR_P 缺失记录。原始数据保留，但不进入权益版本清洗表；不能用 0、前一期或后一期权益填补。
2. 有 10,793 条记录无法解析为六位股票代码，主要是 Axxxxx 形式，例如 A19110、A20471。这些记录无法可靠地与行情表匹配，原始数据保留，但不参与 PB 或 ROE 计算。
3. 不直接截取数字或补零匹配异常代码，避免错误匹配财务主体；以后有证券代码映射表时再复核。
4. 完全重复记录额外删除 2 条，同一报告期不同修订版本保留。

## 4. TTM 和平均权益

EP 的 TTM_ni 直接作为 ROE 分子：

    TTM归母净利润 = EP reports_ttm.parquet 中的 TTM_ni

ROE 另外取得最新报告期和去年同期的归母股东权益：

    平均归母权益 = (本期归母权益 + 去年同期归母权益) / 2

最终计算：

    ROE = TTM归母净利润 / 平均归母股东权益

如果本期或去年同期权益小于等于 0，ROE 设为缺失，同时在 roe_mask.parquet 中记录 negative_equity=1。负净利润保留，因此可以产生负 ROE。

## 5. 点时间对齐

将 EP 的 TTM 事件和 PB 的权益版本事件合并，权益发生修订时也更新 ROE。T 日只使用：

    VERSION_TIME <= T 日结束时间

T 日因子用于 T+1 日交易，后续公告或修订不能回填历史。

行情表中标记的停牌和次新股不进入有效 ROE 样本。历史 ST/PT 数据不可用，因此未推断 ST/PT 过滤。

## 6. MAD 和 Z 标准化

每日横截面计算：

    MAD = median(abs(ROE - median(ROE)))
    下限 = median - 3 * 1.4826 * MAD
    上限 = median + 3 * 1.4826 * MAD
    Z = (MAD处理后的ROE - 当日均值) / 当日标准差

横截面标准差为 0 时，Z 值保留缺失，不填 0。

## 7. 运行顺序

    python roe_step1_读取已清洗行情.py
    python roe_step2_利润表处理.py
    python roe_step3_TTM和平均权益.py
    python roe_step4_点时间对齐_计算ROE.py
    python roe_step5_MAD去极值_Z标准化.py

## 9. 重要限制

1. 历史 ST/PT 标记不存在，当前没有完成 ST/PT 过滤。
2. 次新股使用行情表首次出现日期作为代理，不能替代官方上市日期。
3. 2020 年初财报历史覆盖不足，早期 ROE 有效样本可能较少。
